# Sari-Sari Management System

## Description

Sari-sari store management system with a Dockerized development environment, built using Laravel, React, TypeScript, MySQL, and Tailwind CSS. Repository owner and contributor, responsible for project architecture, database design, and portions of the backend implementation.

> Status: Unfinished

## Development Journey

During development, several environment and deployment challenges were encountered and documented, including:

- WSL configuration and Linux-based development
- Docker networking and container communication
- Laravel file permission issues
- Vite development server configuration
- React + TypeScript integration with Laravel
- Environment replication across multiple machines
- Containerized frontend and backend workflows
- Collaborative development workflows using Git and GitHub
- Development environment onboarding and documentation

## Notes

- This project was created as a collaborative learning project to gain hands-on experience with GitHub-based team development, Docker, and Linux development using WSL.
- A primary goal was to create a consistent development environment that could be easily replicated across different machines using Docker Compose.
- Extensive setup notes and troubleshooting documentation were maintained throughout development to improve onboarding and reduce environment-related issues for collaborators.
- The project is currently under active development and some features remain incomplete.
